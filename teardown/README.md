# teardown/

Real companies that AI already recommends, read to show why.

The `example/` folder uses a made-up company, Ficti, so the plan can be prescriptive without speaking for anyone. These teardowns are the opposite: real, named companies you can verify yourself, used to show what good looks like rather than to give them advice.

- [`tally.md`](tally.md): why AI recommends Tally, a Ghent-based form builder, mapped to the signals in `../system/01-how-ai-recommends.md`.
